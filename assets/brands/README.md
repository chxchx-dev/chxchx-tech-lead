# Marcas de los agentes

Marcas que Studio muestra junto a cada agente para que se reconozca de un vistazo. Pertenecen a sus
dueños (Anthropic, OpenAI y OpenCode) y se usan solo para identificar la herramienta integrada.

| `opencode.svg` | `packages/identity/mark.svg` de [anomalyco/opencode](https://github.com/anomalyco/opencode), reducido a una sola tinta | MIT |

Se dibujan con el color del agente, no con el de la marca original.
