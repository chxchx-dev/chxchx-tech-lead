# Marca de ChxChx

- `logo-420.png`, `mark-256.png`, `mark-40.png`, `chxchx.ico`: el logo (el nudo en X) y su isotipo.
- La **mascota** (el personaje encapuchado con la máscara sonriente, el mismo del prompt `CHXCHX-DEV` del
  terminal) es obra del autor del proyecto. El original no vive en el repositorio: solo las versiones pequeñas
  que usa la app web, derivadas de él, en `apps/remote/web/img/` (`mascot-96.png`, `mascot-288.png`) y en
  `apps/remote/web/icons/` (iconos de la app instalada).
- `apps/remote/web/img/banner.png`: el rótulo `CHXCHX` de bloques del terminal, dibujado como imagen con el
  degradado cian → azul (`#00e5ff` → `#2a70ff`) para que se vea igual en cualquier teléfono, sin depender de
  una fuente con caracteres de caja.
- `mascot-256.png`: la mascota a 256 px, para la ventana de Studio.
- Colores: fondo `#070a10`, acento `#00d9ff`, degradado `#00e5ff → #2a8bff → #3a63ff`.
