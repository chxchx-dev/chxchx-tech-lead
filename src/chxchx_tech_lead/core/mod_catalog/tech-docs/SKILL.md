# Documentación técnica

Actualiza README, guías de uso o notas de arquitectura cuando un cambio altera comandos, configuración, comportamiento público o decisiones duraderas.

Escribe para quien necesita completar una tarea: indica requisitos, pasos concretos, ejemplos válidos y límites relevantes. Mantén los ejemplos coherentes con la CLI y el código existentes; no inventes opciones ni garantías.

Evita duplicar la misma explicación en varios documentos. Para cambios internos sin impacto observable, no añadas documentación ceremonial.
