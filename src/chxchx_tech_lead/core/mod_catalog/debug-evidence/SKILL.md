# Depuración con evidencia

Primero reproduce el fallo o localiza la primera evidencia que lo confirma. Sigue los datos desde la entrada hasta el resultado, formula una hipótesis comprobable y contrástala con una prueba, log o inspección dirigida. Separa causa raíz de síntomas y evita cambios no relacionados.

Antes de editar, resume causa e impacto. Después ejecuta la comprobación más pequeña que detecte la regresión y revisa el diff. Si el fallo no se reproduce, no presentes una hipótesis como causa confirmada.
