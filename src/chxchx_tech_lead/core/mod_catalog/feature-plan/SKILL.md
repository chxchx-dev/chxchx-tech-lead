# Plan de funcionalidad

Antes de una funcionalidad que cruce varias capas, localiza el flujo existente y sus reglas. Resume el resultado esperado, los archivos/capas implicados, compatibilidad, estados de error y criterios de aceptación. Prefiere pasos pequeños que preserven interfaces públicas y aprovechen servicios existentes.

Aclara una ambigüedad solo cuando cambie materialmente el comportamiento; mientras tanto avanza en trabajo independiente. No amplíes el alcance con infraestructura que el producto no necesita. Presenta el plan antes de una reestructuración amplia.
